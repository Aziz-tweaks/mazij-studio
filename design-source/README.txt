مزيج — Mazij Studio (نموذج واجهة تفاعلي)

الملفات:
- Mazij Studio.html
  ملف واحد مستقل يفتح في أي متصفح بدون إنترنت (الخطوط ومحرّك التشغيل مدمجة فيه).

- source/Mazij Studio.dc.html
  الكود المصدري القابل للتعديل: القالب (HTML) + المنطق (JavaScript) + إعدادات التعديلات.

- source/support.js
  محرّك التشغيل الذي يحتاجه الملف المصدري. ضعه بجانب الملف المصدري عند فتحه.

تجربة سريعة:
- زر «بسيط / احترافي» في الشريط العلوي.
- Ctrl K أو Cmd K لفتح شريط الأوامر.
- تبويب «المساعد» ثم اختر الحساب لتجربة المحادثة.
- تبويب «المكتبة» → «الخطوط» → الصق رابطاً واضغط «تحميل».
